# Better Call CodeCH

App móvil Android para estudio y consulta de legislación (MVP académico, DSY1105)

## Funciones
- Registro e inicio de sesión con validación (Room)
- Consulta de normas y artículos, con ajuste del tamaño de letra
- Foto de perfil con la cámara
- Confirmación al cerrar sesión

## Tecnologías
Kotlin, Jetpack Compose, MVVM, Room, Navigation Compose.

Los datos de normas son de ejemplo y no reemplazan las fuentes oficiales de legislación
